# LANCE PRO

Portal de oportunidades em leilões, desenvolvido com React e Vite.

## Rodar localmente
```bash
npm install
npm run dev
```

## Situação atual
Esta primeira entrega é uma prévia visual responsiva com:
- página inicial e identidade visual LANCE PRO;
- vitrine de lotes demonstrativos;
- busca e filtros por categoria;
- detalhes de lote e interação de lance apenas demonstrativa;
- entrada visual para a área do cliente.

## Próximas etapas para produção
1. Conectar autenticação real e perfis de usuário.
2. Criar painel administrativo para cadastrar lotes, documentos, fotos e datas.
3. Persistir lances no banco de dados e validá-los no servidor, com transações e horário oficial.
4. Implementar edital, regras, trilha de auditoria, encerramento e notificações.
5. Configurar hospedagem e domínio.

**Importante:** os lotes e valores atuais são fictícios. Nenhum lance real é aceito ou registrado nesta versão.
